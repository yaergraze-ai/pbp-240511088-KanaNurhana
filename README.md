## Aturan penyimpanan

- Setiap LKP mempunyai **satu folder utama** yang namanya mengikuti judul pada modul.
- Di dalam masing-masing folder, simpan kode program, dokumentasi, screenshot bukti, dan laporan sesuai instruksi LKP.
- Folder yang berisi README dengan keterangan **Belum dikerjakan** adalah wadah persiapan, **bukan** hasil tugas yang sudah selesai.
- Untuk LKP 1, semua hasil praktikum yang sebelumnya berada di root repository sudah dipindahkan ke folder [LKP 1](LKP%201%20-%20Setup%20Environment%20%26%20Eksplorasi%20Platform/README.md).
- File `.gitignore` diletakkan di root repository agar aturan pengabaian file berlaku bagi seluruh praktikum.

**Catatan penamaan Windows:** tanda petik pada judul LKP 5A dan 6A tidak digunakan dalam *nama folder* karena penamaan folder Windows tidak menerima karakter tanda petik; judul asli tetap dicantumkan dalam README.
