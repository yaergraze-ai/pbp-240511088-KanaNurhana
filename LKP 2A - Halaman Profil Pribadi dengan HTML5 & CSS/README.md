## Tujuan

Membuat halaman profil statis menggunakan struktur HTML5 semantik dan CSS dasar, sesuai **Modul dan Lembar Kerja Praktikum Pemrograman Berbasis Platform (2026)**, halaman PDF 16–20.

## Struktur berkas

```text

│   └── foto.jpg
└── README.md
```

## Materi yang diterapkan

- **HTML5 semantik:** `header`, `nav`, `main`, `section`, `footer`.
- **CSS dasar:** font, warna, background gradient, jarak, border-radius, dan hover.
- **Layout:** Flexbox pada navigasi dan CSS Grid pada kartu teknologi.
- **Tautan:** navigasi antarbagian, alamat email contoh, dan profil GitHub.

## Menjalankan proyek

1. Buka folder ini di VS Code.
2. Klik dua kali `index.html` atau gunakan ekstensi Live Server.
3. Pastikan foto, menu Tentang/Keahlian/Kontak, dan kartu tampil.
4. Klik setiap tautan navigasi dan periksa tampilan di browser.
5. Ambil screenshot halaman untuk bukti praktikum dan simpan ke folder ini dengan nama `Lkp 2A - Hasil Halaman Profil.png`.

## Yang harus disesuaikan sebelum dikumpulkan

- Gambar `assets/foto.jpg` **masih ilustrasi avatar generik, bukan foto pribadi**. Ganti dengan foto atau ilustrasi profil yang diperbolehkan dosen. Pertimbangkan privasi sebelum mengunggah foto pribadi ke GitHub publik.
- `email@example.com` pada halaman **hanya contoh dari modul**, bukan email mahasiswa. Ganti jika ingin mencantumkan alamat email yang aman dibagikan.
- Ambil screenshot setelah halaman diuji di komputer sendiri. Screenshot belum ditambahkan karena belum dilakukan verifikasi visual oleh mahasiswa.
- Setelah bukti ditambahkan, commit dan push dengan pesan `update` sesuai preferensi penamaan commit repository.
