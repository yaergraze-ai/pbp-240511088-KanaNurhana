## Tujuan

Membuat halaman profil statis menggunakan HTML5 semantik dan CSS dasar sesuai Modul dan Lembar Kerja Praktikum Pemrograman Berbasis Platform tahun 2026 (PDF halaman 16–20).

## Struktur berkas

- index.html — isi dan struktur semantik halaman
- style.css — warna, font, spacing, layout Flexbox dan Grid, responsivitas
- script.js — interaksi tambahan tanpa framework
- assets/foto.jpg — avatar ilustrasi sementara, bukan foto asli
- README.md — petunjuk dan penjelasan praktikum

## Fitur yang dibuat

- Bagian Beranda, Tentang Saya, Keahlian, dan Kontak.
- Identitas mahasiswa: nama, NIM, kelas, dan universitas.
- HTML semantik: header, nav, main, section, article, aside, footer.
- CSS Grid untuk layout dan kartu teknologi, Flexbox untuk navigasi dan tombol.
- Desain modern dengan gradient, tipografi, kartu identitas, spasi, dan hover.
- Tambahan JavaScript murni: mode gelap/terang, indikator scroll, navigasi aktif, animasi masuk saat scroll, dan tahun otomatis.
- Dukungan aksesibilitas keyboard, label tombol, serta pengurangan animasi pada preferensi reduced motion.

## Cara menjalankan

1. Buka folder LKP 2A ini di VS Code.
2. Buka index.html lewat Chrome/Edge atau ekstensi Live Server.
3. Uji menu Beranda, Tentang, Keahlian, dan Kontak.
4. Uji tombol mode gelap/terang, hover kartu, dan tampilan pada layar kecil.
5. Ambil screenshot hasil pengujian di laptop dan simpan dengan nama Lkp 2A - Hasil Halaman Profil.png.
